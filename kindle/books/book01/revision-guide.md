# book01 改訂版の手順(体験談差し込み改訂)

体験談が5〜10件たまったら、以下の手順で改訂版を出します。
KDPは出版後も原稿の差し替えが可能で、既存の商品ページ・レビューは維持されます。

## 手順

1. **材料の確認**: experience-log.md のメモを編集部(Claude)に渡す
2. **差し込み編集**: 編集部が該当章の「一般的な場面例」を実体験ベースの記述に置き換え
   (writerが下書き→あなたが表現を確認。数値・固有名詞はあなたのメモの範囲のみ使用し、盛らない)
3. **editorチェック**: 校正+AI申告判定の更新
   - 注意: 本文の元はAI作成のため、体験談を差し込んでも判定は**「AI生成(申告必要)」のまま変わらない**
     (ai-declaration.md の判定基準参照)。申告内容の変更手続きは不要
4. **/publish-check 再実行**: チェック結果を publish-check-YYYYMMDD.md として保存
5. **EPUB再生成**: manuscript.md 再結合 → book01.epub 再生成(pandoc)
6. **KDPで原稿差し替え**: 本棚 → 対象書籍 → 電子書籍の内容を編集 → EPUBアップロード → 出版
   (反映まで最大72時間。価格・説明文の変更も同時に可能)
7. **記録**: publication-record.md に改訂日と変更概要を追記

## 改訂のタイミング目安

- レビューで内容の指摘があったとき(誤り修正は速やかに)
- 体験談が5件以上たまったとき(説得力の底上げ)
- 2冊目出版時(巻末に相互紹介を入れる改訂と同時に行うと効率的)

## 改訂版でやらないこと

- タイトル・表紙の大幅変更(別の本と誤認される。やむを得ない場合はKDPのガイドラインを確認)
- レビューへの反論的な追記
- 体験談の創作・誇張(実際にあったことだけを書く)
