# book01 体験談収集ノート(改訂版の材料)

現場でAIを使った実体験を、思いついたときにここへメモしてください。
5〜10件たまったら改訂版に差し込みます(手順は revision-guide.md)。

書き方のコツ:
- 1件3〜5行でOK。「場面 → 使う前の困りごと → AIへの頼み方 → 結果・気づき」の順
- 顧客名・社名・具体的な商品名は伏せる(「量販店のお客様」「法人のお客様」程度に)
- 失敗談も価値が高い(AIの回答が使えなかった話、言い回しを直した話など)

## 章別の差し込み候補箇所

現在「一般的な場面例」になっている箇所です。対応する実体験があれば優先的にメモしてください。

### 第1章(AIを使い始めたきっかけ)
- [ ] あなたが最初にAIを仕事で使った場面と、そのときの驚き・変化

### 第2章(スマホ運用)
- [ ] 実際のスマホの使い方(使う時間帯・音声入力の頻度・1日何回くらいか)

### 第3章(メール・チャット)
- [ ] お礼メール・日程調整・社内報告で実際に時短できた例(before/after)

### 第4章(提案・商談準備)
- [ ] 下調べ・提案書たたき台・想定問答で使った実例
- [ ] AIの回答が古かった/間違っていたので裏取りで助かった実例

### 第5章(接客・クレーム対応)
- [ ] お詫び文・難しいお客様への返答づくりに使った実例(伏せ字で)
- [ ] 断り文句(値引き・納期など)の言い回しを整えた実例

### 第6章(日報・報告書)
- [ ] 音声入力×AI整形の実際の運用と、かかる時間の変化

### 第7章(続けるコツ)
- [ ] 会社ルールの確認をどう切り出したか
- [ ] AIの間違いに気づいた実例/プロンプト帳の実物(見出し構成)
