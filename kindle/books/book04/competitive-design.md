## 0. 結論サマリ(先に読む)

1. **先行17冊シリーズは脅威ではない。** 楽天Kobo限定、**全17冊がレビュー0件・ランキング圏外**、
   商品説明に `**太字マークダウン**` が生のまま残っている(=AI出力の未整形貼り付け)。
   Amazon・BOOK☆WALKER・版元ドットコム・Web全般に存在が確認できない**単一ストアの量産レーベル**である。
2. **本当の脅威は資格者と当事者体験記である。** 2026年5月に**社労士(392ページ)とFP(263ページ+紙版併売)**の
   大型新刊が2冊出ており、Kindleには**当事者体験記が10冊以上、レビュー19〜89件**で居座っている。
3. **したがって「先行者の弱点=当事者性ゼロ。だから当事者性で勝つ」という前提は成立しない。**
   当事者性はこのニッチで**最も希少でない資源**である(§3.1)。これが本レポート最大の発見で、
   `critique-market.md` §2-5 と `FINAL-5-candidates.md` 第1案の差別化軸を**否定する**。
4. **先行者が押さえた「順番」は、この領域では死語だった。** 知恵袋で
   「傷病手当金 順番」**219件** / 「休職 順番」**576件**。
   一方「休職 やってはいけない」**16,650件**、「事業主証明」**14,527件**、
   「傷病手当金 書いてくれない」**12,677件**。先行者はタイトルを**需要の無い語**に当てている(§4.1)。
5. **判定: 第1案(休職・傷病手当金を25〜28冊に展開して月10万円)は勝てない。**
   ただし**「休職の入口」1巻に絞り、制度の数字を最小化した別設計なら勝てる余地がある**(§7)。
   勝てる内容と勝てない内容を §8 に分けて書いた。

### 2.2 この表から読める3つの事実

**(1) レビューが付いているのは全部「当事者体験記」である。制度解説書には付いていない。**
19〜89件の7冊は**全員が当事者**。一方 FP(263p)は2件、社労士(392p)は不検出。
→ 読者はこの領域で**体験記を読んでレビューを書き、制度書はレビューを書かない**。
→ 当事者性は**差別化の武器ではなく、このニッチの参加費**である。

**(2) 2026年5月に、資格者による大型新刊が2冊同時に出た。**
社労士392ページ、FP263ページ+紙版併売1,250円。どちらも「完全ガイド」型。
**網羅性の軍拡競争は2026年に入って一段上がっている。**

**(3) CLAUDE.md の参入ゲートは、ギリギリ通る。**
> 狙い目の判定：Amazon検索上位30冊にレビュー10件未満の本が複数入っているジャンル＝競合が弱く参入余地あり。
> 逆に上位が全てレビュー100件超なら避ける

最大が89件で、2件・5件の本が複数ある。**「全てレビュー100件超」ではないので禁止には当たらない。**
ただし「競合が弱い」とも言えない。**上位30冊の順位は503で取得できていない**ため、
このゲートは**本精査でも適用できていない**(`critique-market.md` §13-1 と同じ未了点)。

### 2.3 【重要】差別化の核だと思われていたニッチは、すでに社労士が書いている

`critique-market.md` §2-5 は「却下を覆す唯一の条件」として
**「会社が協力しない／自分が動けない前提で手続きを完了させる実務」**を挙げた。

**これは労務のあかり『傷病手当金は「組み立て方」で変わる』(392ページ、社労士)に既に入っている。**
検索スニペットから確認できた同書の記述:

> 会社を通さない直接申請ルートを解説。事業主記入欄だけ会社に書いてもらい、医師証明は自分で取得、
> 保険者に直接郵送

> 待期3日・医師意見書・事業主証明・マイナポータル電子申請

> 「労務不能」を動詞で伝える。「忙しい」ではなく業務動作で具体的に伝えると意見書が通りやすい

→ **「相手が協力しない前提」という軸は、空白ではない。社労士が資格の裏付け付きで押さえている。**
本プロジェクトがこの軸で正面から戦えば、**392ページ・社労士・KU対象750円**に対して、
**無資格・AI生成申告あり・レビュー0** で挑むことになる。これは勝てない。

## 3. 差別化の設計(本タスクの核心)

### 3.1 まず、与えられた前提を1つ訂正する

タスク指示は「先行者の弱点は当事者性ゼロと分かっている。この一点でどう勝つか」である。
**この前提は、精査の結果、使えない。**

- 先行17冊シリーズは**レビュー0・ランキング圏外・Kobo単独**で、そもそも競合として機能していない。
  これに勝ってもAmazonでの売上は1円も動かない。
- 実際に読者を持っている競合は**当事者体験記7冊(19〜89件)**であり、**当事者性では一切差がつかない**。
- 制度の正確性で勝っている競合は**社労士392p・FP263p・産業医(ディスカヴァー)**であり、
  **網羅性でも権威性でも勝てない**。

**したがって差別化軸は「当事者性」単独ではありえない。**
希少なのは当事者性ではなく、**次の3つの交点**である。

| 持っている層 | 当事者性 | 制度の正確さ | 「相手が協力しない」 | **「自分が動けない」** | 短く使える形 |
|---|---|---|---|---|---|

### 3.2 差別化の核 — 「順番」ではなく「捨てる順番」を売る

既存の全競合は、**読者が動けることを前提に「全部の順番」を書いている**。
先行者のタイトルがまさに「順番」であり、巻末資料は「全体の流れ早見表/チェックリスト10項目」である。

だが知恵袋の生の声は、順番を知らないのではなく**動けない**:

> 「職場の人からのLINEトーク開くだけで気分悪くなります。休職中で辞めたいが勇気が出ない。
>   傷病手当金の手続きのために来て欲しいと言われました」
> 「会社から来るように言われ続けて本当に心身ともに疲労困憊です。端的な返答で結構です」
> 「朝起きて会社に行こうと思ったら吐いてしまい」

**「端的な返答で結構です」。これが読者の本音であり、40,000字の「全体の流れ」はこの読者に届かない。**

そこで本企画の中心命題を、こう置く:

> **制度の全部を順番どおりにやるのは無理である。**
> **だから「期限が切れたら取り返せないもの」だけを残し、残りは全部あとでいいと決める。**

これは **トリアージの本** である。先行者が売る「網羅と順番」の裏返しであり、
**当事者でなければ書けず、資格者には書けない**(資格者は「全部やりましょう」以外書けない。
「これは捨ててよい」は職業上言えない)。かつ**制度の数字をほとんど使わないので、
CLAUDE.md が最も警戒する「誤記1行で給付を失う」リスクが構造的に小さい**。

### 3.3 構成レベルの設計(1巻分)

#### 中心の仕掛け:「今日の1個」カード方式

全章を **「今日できることが1個だけだとしたら、これ」** という単位に割る。
章ではなく**カード**を並べる。読者は上から読むのではなく、**今日の体調に合うカードを1枚引く**。

各カードの固定フォーマット(全カード共通。水増し不可の形にする):

```
■ カード N ──────────────────
いつまで    : (期限。無ければ「期限なし=あとでいい」と明記)
捨てたらどうなる: (損失。無ければ「何も起きない」と明記)
所要         : (電話1本 / 封筒1通 / 5分 / 半日)
体調         : (寝たままできる / 座れればできる / 外出が必要)
やること      : 動作だけを3行以内
相手が断ったら : ← ★この行を全カードに必ず置く
自分が動けない日は: ← ★この行を全カードに必ず置く
───────────────────────────
```

**「相手が断ったら」「自分が動けない日は」の2行を全カードに強制する**のが設計の要。
既存の制度本はこの2行を持たない。持てない。**当事者だけが全カードに書ける。**

#### 章立て(案)

| 部 | 内容 | 当事者性が載荷するか | 制度の数字 |
|---|---|---|---|
| **第0部** | **期限があるのは4つだけ**(それ以外は全部あとでいい)。捨ててよいもの一覧 | ◎ | 最小 |
| 第1部 | **言い出す** — 上司に言えない日の言い方。電話が無理ならメール、メールが無理なら書面。家族に言えない | ◎◎ | **ゼロ** |

これが差別化であり、同時に**ハルシネーション事故の最大の予防策**である。

### 3.4 読者が先行者の本ではなくこちらを選ぶ理由(1文)

> **先行者の本は「制度の全部の順番」を教えるが、この本は「今日の体調でできる1個」と
> 「相手が書いてくれないときの次の一手」しか書いていない。**

ストア向けの1文(商品説明の冒頭に置く形):

> **会社も医師も動いてくれず、自分も動けない。その日のための本です。
> 全部やる順番ではなく、今日やる1個と、断られたときの次の一手だけを書きました。**

### 3.5 やってはいけないこと(社労士法・CLAUDE.md 遵守)

本設計は資格法の境界に近いので、以下を執筆規約として確定する。

- 「あなたの場合は受給できます/できません」を書かない。第6部は**金額を断定せず「確認先と聞き方」のみ**
- 「代行します」「申請を代わりに出します」を書かない。**個別相談チャネルを一切作らない**(CLAUDE.md)
- 医師に対する働きかけは「**自分の状態をどう言葉にするか**」に限る。
  「こう書かせる」「この病院なら出る」は書かない(『うつ病の診断書をすぐもらえる病院ってある？』の路線を取らない)
- 診断・治療・薬に触れない(CLAUDE.md「心身の不調に関わるテーマの線引き」)
- 「甘え」「頑張れ」「考え方を変えよう」を一語も書かない(不満類型⑤)

1. **時系列で最も手前にある。** 読者は「言い出す」→「診断書」→「申請」→「お金」→「復職/退職」と進む。
   入口を取れば read-through の起点になる。網羅本を1巻目に置くと、2巻目に進む動機が消える。
2. **制度の数字がほぼ出てこない。** CLAUDE.md が最も警戒する
   「誤記1行で読者が最長1年6か月分の給付を失う」リスクが、**この巻では構造的にほぼゼロ**。
   初めての制度系書籍で、事実検証工程を確立しながら出せる。
3. **当事者性が最大に載荷し、資格者が書けない。** 「上司に何と言ったか」「言えなかった日に何をしたか」は
   社労士もFPも産業医も書けない。一方、傷病手当金の計算は彼らの方が正確に書ける。
   **当事者が勝てる唯一の領域に第1巻を置く。**
4. **競合が最も薄い。** この区画で見つかった本は『うつ病の診断書をすぐもらえる病院ってある？』1冊のみ。
   網羅本区画(社労士392p/FP263p/産業医/先行者)と比べて密度が桁で違う。
5. **先行者と正面衝突しない。** 先行者のタイトルは「傷病手当金・休職・復職」。
   こちらは「言い出せない・伝え方・診断書」。検索語が重ならない。

**次善: タイトル案5『休職中のお金が止まる前に』**(「休職 お金」42,987件が先頭に立つ)。
ただし制度の数字が中量入るため、事実台帳の工程を確立したあと=第2巻以降が安全。

**非推奨: タイトル案2**(社労士392pと正面衝突)。

## 8. 判定 — この企画は勝てるか

### 8.1 勝てない(明確に)

**『FINAL-5-candidates.md』第1案「人生が止まったときの手続き」25冊シリーズで月10万円** は、
**勝てない。** 根拠5点:

1. **差別化軸として設定された「当事者性」が、このニッチでは希少資源ではない。**
   Kindleに当事者体験記が10冊以上あり、**レビュー19〜89件を持っているのは全部当事者**である。
   当事者性は参加費であって優位ではない(§2.2)。
2. **「相手が協力しない前提」という残余ニッチは、2026年5月に社労士(392ページ)が埋めた。**
   会社を通さない直接申請ルート・事業主証明・医師への伝え方まで書かれている(§2.3)。
   `critique-market.md` が「却下を覆す唯一の条件」としたものが、すでに資格者に取られている。
3. **網羅性の軍拡が2026年に一段上がった。** 社労士392p / FP263p+紙版1,250円 / 産業医×ディスカヴァー1,870円。
   680円・25,000字・AI生成申告ありで、この3者に検索順位で勝つ道筋が描けない。
4. **先行17冊シリーズが、4か月でレビュー0・ランキング圏外という結果を出している。**
   これは「鉱脈があるのに掘られていない」のではなく、**「この鉱脈に17冊投下しても露出が生まれない」
   という実測データ**である。本プロジェクトが25冊で同じことをやる根拠にならない。
5. **週2タイトル制限下の作業時間で25〜28冊=3〜4年。** その間、制度改正ごとに全巻の改訂義務を負う
   (改訂もAI申告が必要)。**冊数が負債に転じる**。

**加えて、`FINAL-5-candidates.md` の編集部結論①が依然として正しい。**
既刊3冊は露出ゼロであり、0×3=0 に新刊を足しても 0×4=0。**題材を変えても解決しない。**

### 8.2 勝てる(条件付き・ただし「勝ち」の定義を下げる)

**『休職を言い出せないとき』を1冊だけ出す**という縮小版なら、勝てる余地がある。
「勝ち」の定義は **月10万円ではなく「レビューが5件付く」**。

必要条件(すべて満たす場合のみ):

- [ ] **著者に休職・療養の当事者経験があること。** 無ければこの企画は全面的に不可
      (当事者性は優位ではないが、**無いと参加すらできない**)
- [ ] **第1巻の射程を「言い出す・診断書・会社と接触しない」に限定し、傷病手当金の金額計算に踏み込まないこと。**
      網羅本にした瞬間、社労士392pとFP263pとの比較に入り負ける
- [ ] **全カードに「相手が断ったら」「自分が動けない日は」の2行を置くこと。** これが唯一の構造的差別化
- [ ] **価格480〜580円。** 680円(先行者と同額)で出さない
- [ ] **分量25,000〜30,000字。** 40,000字を狙わない(不満類型②の回避を優先)
- [ ] **数値の全数台帳化(facts-ledger.md)と独立3ソース一致を、この巻では「保険料・住民税」の数行だけに限定**
      できる設計にすること。できないなら巻の射程が広すぎる
- [ ] **個別相談チャネルを作らない。** 巻末LINE・メール相談・レビュー返信での個別助言を一切しない
- [ ] **著者がブラウザで以下3点を目視確認すること**(本環境では503で不可):
      ① Amazon内「くらしの制度ガイド編集部」の有無
      ② 「休職 手続き」「傷病手当金」のAmazon内検索上位30冊のレビュー件数分布(CLAUDE.md の参入ゲート)
      ③ 労務のあかり『傷病手当金は「組み立て方」で変わる』の目次(第3〜4部との重複の実測)
- [ ] **露出の入口を1本持つこと。** 無料記事(note/はてな)の受け皿を本より先に作る。
      これが無ければ、先行17冊と同じ「レビュー0」に着地する。**ここが最大の分岐点で、本の中身ではない**
