## 1. 読者の悩みの言葉（検索語・よくある相談）

### わかったこと（出典付き）

Q&Aサイト（Yahoo!知恵袋）・悩み系記事の見出しレベルで確認できた「現場の人の生の言葉」:

- 「**クレームを受けて落ち込んでいます…。どうしたら立ち直れるでしょうか**」
  （知恵袋の質問タイトル: detail.chiebukuro.yahoo.co.jp/qa/question_detail/q10113371710）
- 「**クレームが怖いです。接客業をしています。私は決して雑な対応をしている訳では…**」
  （知恵袋 q12273063807。※本文403で未読。「自分は悪くないのに怖い」という構図）
- 「**名指しでクレームが入り辛いです。先日1年ほど務めているバイト先で初めて…**」
  「**接客業名指しクレームについてです。自分自身レジに関しては愛嬌…**」
  （知恵袋 q11298296116 / q13253680043。名指しクレーム＋「心当たりがない」「本社まで話が行った」）
- 記事見出しの傾向: 「接客のクレームで落ち込むのはもう終わり」（Zキャリア）、
  「もう怖くない！クレームの電話対応」（オムニコンタクト）、「接客が怖い！克服するには」
  （おもてなしHR）、「名指しでクレームを受けた！イライラを回避する方法」（おもてなしHR）、
  「バイトで名指しクレームを受ける原因と対処法」（baito-taiken.net）
- 悩みの型の整理（複数記事・Q&Aから共通して読み取れるもの）:
  1. **怖い・予測できない**（何を言われるかわからない、怒鳴り声が怖い、泣きそうになる）
  2. **言い方がわからない**（最初に何と言えばいいか、謝りすぎていいのか）
  3. **落ち込む・引きずる**（名指しクレームがショック、心当たりがないのに責められた、辞めたい）
  4. **自分は悪くないのに**（店のルール・商品の問題でも自分が矢面に立つ）
- 検索語として実在が確認できた系統: 「クレーム対応 言い方」「クレーム 怖い」「接客 クレーム
  落ち込む」「名指し クレーム」「クレーム 電話 怖い」「クレーム対応 例文/フレーズ」

### 本文への活かし方

- **第1章導入**: 「怖い本当の理由＝予測できない」は読者の言葉と一致。知恵袋タイトル級の
  言葉（「落ち込んでいます」「私は雑な対応をしていないのに」）を導入の共感パートの語彙にする
  （転載ではなく同じ悩みを自分の言葉で書く）。
- **第4章・第6章**: 「名指しクレーム」「心当たりがないのに責められた」は第6章
  （引きずらない）の場面として頻出・共感度が高い。骨子の【要追記】に「名指しでクレームを
  受けた経験の有無」を著者ヒアリング項目として追加推奨。
- **タイトル・商品説明文**: 「最初の30秒で何と言えばいいのか」という商品説明冒頭案は
  悩みの型2（言い方がわからない）と合致しており変更不要。

## 2. 場面別の頻出クレームパターン

### わかったこと（出典付き）

**飲食**（マネーフォワード クラウド、SST、Food's Route、クックビズ総研、レストランスター等の
解説記事で共通）:
- 接客態度（私語が多い・態度が冷たい・目を見て話さない）※感情的クレームになりやすい
- 待ち時間（注文して30分待った・後から来た人の料理が先に来た）
- 注文相違（頼んだ料理が来ない・違う料理が来た）
- 料理の質（味・鮮度・盛り付け）、異物混入（髪の毛等）、衛生面

**小売・レジ**（アキナイラボ〈スマレジ〉、tenink.net、知恵袋の実例質問）:
- **値札と実際の価格の不一致**（棚の表示と違う金額を取られた）→ 対応は「返品」「差額返金」
  等で店の指示に従う構図。知恵袋にも消費者側からの質問が複数あり頻出場面と裏付け
- レジの打ち間違い（預かり金額の入力ミス・商品価格の入力ミスの2パターン）、お釣りの間違い
- 商品不良・返品返金要求（各社解説記事で定番場面として扱われる）

**業種横断・カスハラ寄りの実態データ**（UAゼンセン「カスタマーハラスメント対策アンケート
調査結果」2024年6月発表、組合員約3万人規模。uazensen.jp にPDF公開、日経・JILPTも報道）:
- 直近2年で迷惑行為の被害にあった人の割合 **46.8%**（前回調査より低下、流通系では約5割の報道）
- 印象に残っている迷惑行為の内訳: **暴言39.8%、威嚇・脅迫14.7%、同じ内容を繰り返す
  クレーム13.8%、長時間拘束11.1%**
- 勤務先の対策は「特に対策していない」42.2%
- ※比率は調査回・設問により異なるため、本文で引用する際は**PDF原本の当該ページを要確認**

### 本文への活かし方

- **第3章の4場面**（商品不良/待ち時間・混雑/接客態度への指摘/返品・返金）は頻出パターンと
  一致しており妥当。小売読者向けに「**価格・レジの違い**（値札と違う・お釣りが違う）」を
  4場面のいずれか（商品不良または返品返金の節内）にサブ場面として足すと網羅感が出る。
- **第5章**: UAゼンセン調査の数値は「あなただけではない」という安心材料として最適。
  出典名・調査年を明記して使う（数値は原本PDFで要確認）。
- 飲食の「異物混入」「注文相違」は著者の業種経験がなければ深追いせず一般例と明示（outline方針通り）。

## 3. 初動対応のセオリー（定説と出典）

### わかったこと（出典付き）

複数の研修会社・企業向け解説で**ほぼ共通して**言われている初動の原則:

1. **部分謝罪（限定謝罪）から入る**: 最初のお詫びは「不快な思いをさせたこと・手間を
   かけさせたこと」への謝罪に限定し、事実確認前に非を全面的に認める「全面謝罪」はしない。
   - 「全面謝罪＝全ての間違いがこちらにあると認めるお詫び / 部分謝罪＝事実によって
     お客様が感じた気持ちに対するお詫び。初期対応で必要なのは部分謝罪」
     （カイクラ.mag、NECネッツエスアイ、日本実業出版社コラム「まず謝罪するは◯か×か」等で共通）
   - フレーズ例（複数サイト共通の型）: 「ご不快な思いをさせてしまい申し訳ございません」
     「ご不便をおかけして申し訳ございません」「ご足労をおかけし申し訳ございません」
2. **傾聴**: 話を最後まで遮らずに聴く。先回りの説明・途中での反論は怒りを増幅させる
   （insource、IEC、三越伊勢丹ヒューマンソリューションズ等）。あいづちは
   「はい」「そうなのですね」「ごもっともです」等（insourceは「話の40〜50%程度に留める」
   としている。※この比率は同社独自の目安であり定説として断定しない）
3. **心情理解・共感の言葉**: 「お気持ちはよくわかります」「さぞご不快な思いを…」
4. **事実確認**: 5W1Hで整理。一度に聞き出そうとせず短く質問。わからないことを
   安請け合いしない。メモ・復唱
5. **解決策・代替案の提示 → お詫びと感謝で締める**: 「ご指摘いただきありがとうございました」
   まで含めて1セット（insource研修、リコー、アチーブメントHRS、Tayori等で共通の手順）
- **時間軸の定説**: 「クレーム対応の成否は最初の3分で決まる」という言い方が複数サイトに
  ある（本書の「初動の30秒」はこれと矛盾しない。「最初の一言」に絞る本書の切り口は独自でOK。
  「9割決まる」等の数値断定は出典がぶれるため**比喩として書くか断定を避ける**）
- **三変主義（人・場所・時間を変える）**: こじれた場合は対応者を上司に代える／場所を
  変える／日を改める、が研修業界の古典的手法として複数社で紹介
  （マネジメントサポート、東京テレマーケティング、センチュリーアンドカンパニー等。
  呼称は「三変主義」「三変法」「三変対応」と揺れる。**呼称の由来は要確認**なので
  本文では「昔から研修などで教えられている方法」程度の紹介に留めるのが安全）
- **クッション言葉・マジックフレーズ**: 「恐れ入りますが」「お手数ですが」等を挟むと
  受け止めやすくなる（マネジメントサポート、insource）

### 本文への活かし方

- **第2章**: 骨子の主張「部分謝罪＋傾聴」は業界の定説と完全に一致。
  「研修の世界でも『部分謝罪（限定謝罪）』と『全面謝罪』は区別されている」と
  定説として紹介してよい（研修会社系コラムで広く共通、と添える）。
  そのうえで「現場で自分が使っている一言」を著者の実例で上書きする構成が差別化になる。
- **第2章の「場所を変える・人を代える」節**: 三変主義として定番の裏付けあり。
  「新人は『人を代える＝逃げ』ではなく手順の一部」という等身大の書き方ができる。
- **第7章**: 「感謝で締める」（ご指摘ありがとうございました）はリピーター化への
  橋渡しとして定説側の裏付けあり。

## 4. 競合の切り口の深掘り（差別化ポイント）

### わかったこと（出典付き）

- **援川聡『クレーム対応「完全撃退」マニュアル』**（ダイヤモンド社。楽天ブックス・
  ダイヤモンド社ページ・diamond.jp連載）: 「100業種・5000件を解決したプロが明かす
  23の技術」。切り口は**「撃退」**。S言葉・「ギブアップトーク」・「3点ピンポイントお詫び法」・
  「積極的放置」など**技名のついたテクニック集**。悪質クレーマー対策の色が濃い。
  元警察官という経歴が訴求軸。
- **津田卓也『どんなクレームも絶対解決できる！』**（あさ出版。HMV・丸善ジュンク堂の
  書誌情報）: 構成は「プロローグ: 正しいクレーム対応の前に知るべき3つのこと / 1章
  一般クレーム対応が基本 / 2章 特殊クレーム / 3章 組織で対応する仕組み / 4章 悪意クレームの
  撃退 / 5章 折れない心と書き込み式オリジナルマニュアル」。**研修講師（リピート率100%訴求）**
  の網羅型。読者は現場個人というより研修対象の従業員〜管理者。
- **山下由美『クレーム対応 最強の話しかた』**（ダイヤモンド社。紀伊國屋書誌・
  diamond.jp連載・note書評）: 「役所窓口で1日200件を解決！指導企業1000社」訴求。
  核は**「そうなんです」と言わせるYメソッド**という独自メソッドの体系。タイプ別攻略・
  プロクレーマー判別チェックリスト付き。
- 共通する訴求構造: **①実績数値（5000件/研修1000社/リピート率100%）②独自メソッドの
  命名 ③「撃退・絶対解決」という強い約束 ④網羅型（一般〜悪質まで全部入り）**。
  読者への立ち位置は「先生が教える」。
- 一方カスハラ本（2024〜2026新刊）は企業・管理者向けに偏る（research-20260806-book02-claim.md）。

### 本文への活かし方（差別化の明文化）

本書が取るべき（既に企画書が取っている）逆張りポイントを執筆時も一貫させる:

1. **実績訴求をしない**: 「5000件解決」ではなく「失敗して覚えた」。まえがきで
   「私は講師ではなく現場の一人」と立場宣言する。
2. **撃退しない**: 「撃退・論破」語彙を本文で使わない。守るのは自分と店、
   相手は「怒っているお客様」であり敵ではない（第1章の主張と一致）。
3. **網羅せず場面を絞る**: 定番書が「全業種・全クレーム」を謳うのに対し、
   本書は接客・販売・営業の対面/電話の頻出4〜5場面だけを深く。
4. **メソッド名で売らない**: 独自メソッドの命名はせず「そのまま口に出せる言い方」と
   「3行記録で自分の型を育てる」（第7章）に留める。※「初動の30秒」はタイトル上の
   フックであり、本文では「最初の一言」の実例で示す。
5. **悪質クレーマー対策は書きすぎない**: 撃退ノウハウは定番書の土俵。本書第5章は
   「線引きして組織に引き継ぐ・記録する・一人で抱えない」まで（outlineの方針通り）。
   これが「現場の一人」ポジションの一貫性になる。

## 5. NGワード・NG対応の定説

### わかったこと（出典付き）

複数ソース（電話代行ビジネスインフォメーション、クレームナビ、HRドクター、コラボス、
リコー、Tayori、日本教育クリエイト、弥報Online、マネジメントサポート等）で共通するNG:

**NGワード**
- **D言葉**: 「でも」「だって」「ですから」「だから」「どうせ」— 否定・言い訳の接頭語として
  複数サイトが共通して名指しする定説。相手の話を遮って反論する形になり感情を刺激する
  （※「D言葉」という呼称自体も研修業界で広く使われており紹介可。対になる「S言葉
  〈失礼しました・承知しました等〉」は援川氏の本などで使われる呼称のため、
  使うなら出典を添えるか一般語で言い換える）
- 「規則ですので」「決まりですから」の突き放し（骨子第4章と一致）
- 「普通は〜」「絶対〜です」等の断定・見下し表現（クレームナビ等）
- 安易な「必ず」「絶対」の約束（できない約束はしない、が共通原則)

**NG対応**
- 話を遮る／最後まで聞かない（ほぼ全ソース共通・最頻出）
- **たらい回し**（担当を転々とさせ同じ説明をさせる。二次クレームの典型原因として共通）
- 言い訳から入る・責任転嫁（「担当が休みでして」等）
- 上司に報告・相談しない（抱え込み）
- 顧客を長時間待たせる
- 「またか」のマンネリ対応・マニュアル棒読み（毎日クレームを受ける側の慣れが、
  お客様には「初めての訴え」を軽く扱われた体験になる — マネジメントサポート等）
- わからないことの安請け合い（あとで約束不履行の二次クレームに）

### 本文への活かし方

- **第4章**: 骨子の5つのNG（言い訳から入る/規則ですので/さえぎる/安易な約束/たらい回し）は
  すべて複数ソースで裏付けあり。定説として安心して書ける。
  D言葉は「でも・だって・ですから」として紹介し、「研修の世界ではD言葉と呼ばれる」と
  一言添える形が自然（特定書籍の独自用語ではなく業界共通語のため）。
- **第3章の「NGの言い方→言い換え」**: NGワード側の材料はこのリストから、
  言い換え側は項目3の部分謝罪・クッション言葉から組める。
- **第2章**: 「話を遮らない」が最頻出NGである事実は、傾聴を初動の柱に置く根拠になる。

## 執筆チームへの申し送り

### ① 各章で使える具体的な場面リスト

- **第1章**: 名指しクレームで落ち込む場面 / 「何を言われるか予測できない」怖さ /
  怒鳴り声で頭が真っ白になる場面（知恵袋・悩み記事の頻出パターン）
- **第2章**: 電話クレームの第一声 / 売り場・レジ前で突然怒鳴られる /
  こじれて場所・人を変える判断の場面
- **第3章**: 商品不良 / 待ち時間・混雑（注文が遅い・後の人が先） / 接客態度への指摘
  （名指し含む） / 返品・返金要求 / ＋サブ場面: 値札と価格が違う・お釣りが違う（小売）
- **第4章**: たらい回しにしてしまった / 「規則ですので」と言ってしまった /
  その場しのぎで「必ず○○します」と約束してしまった、の失敗場面
- **第5章**: 暴言・威嚇・長時間拘束・同じ内容の繰り返し（UAゼンセン調査の上位4類型が
  そのまま「線引き対象」の場面リストになる）
- **第6章**: 名指しクレーム後の帰り道・翌朝 / 心当たりがないのに責められた夜
- **第7章**: 初動→解決→後日フォローで常連化した場面（著者実話が最優先。
  なければグッドマンの法則の一般論で支える）

### ② 定説として書いてよいこと / 出典を添えるべきこと / 断定を避けるべきこと

**定説として書いてよい（複数ソース共通・出典なしでも一般論として成立）**
- 部分謝罪（限定謝罪）と全面謝罪の区別。初動は部分謝罪＋傾聴
- 話を最後まで聴く・遮らない・復唱・メモ・5W1Hの事実確認
- D言葉（でも/だって/ですから）がNG、たらい回し・言い訳・安易な約束がNG
- こじれたら人・場所・時間を変える（呼称「三変主義」は「〜と呼ばれる」程度に）
- 最後に感謝を添える（ご指摘ありがとうございました）

**出典を添えるべき（数値・固有名詞つきの主張）**
- UAゼンセン調査の数値（46.8%、暴言39.8%等）→「UAゼンセン2024年調査によると」＋
  **原本PDFで数値を要確認**（uazensen.jp）
- グッドマンの法則（クレーム解決経験者の方がファンになりやすい）→ 名前を出すなら
  「グッドマンの法則として知られる」と紹介。数値（再購買率○%等）はソースによって
