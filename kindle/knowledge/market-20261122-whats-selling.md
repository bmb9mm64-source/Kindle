# Kindle個人出版 市場リサーチ: いま実際に売れている/読まれているもの

- 調査日: 2026-11-22
- 調査者: 市場リサーチャー(サブエージェント)
- 目的: 一般的な「おすすめジャンルまとめ」ではなく、**一次情報に近い実データ**から、いま参入すべき領域を特定する

## 調査手法と制約(重要)

| 項目 | 状況 |
|------|------|
| Amazon.co.jpの商品/ランキングページ本文取得 | **不可**。`/gp/bestsellers/`、`/dp/` ともに全て HTTP 503。CDNミラー(`www.cdn.amazon.co.jp`、cloudfrontドメイン)も503。curl経由も環境ポリシーで拒否 |
| `allowed_domains: ["amazon.co.jp"]` のWebSearch | **一部可**。検索エンジンのスニペット経由で、実在タイトル・著者名・レビュー数・ランキング順位の断片は取得できた。ただし**取得日時が不明**で、ランキング全体の構成比は取れない |
| 個人出版者のnote/ブログ | 取得可。自己申告データが中心だが、**実数字を出している記事を優先**した |
| KDP公式ヘルプ(kdp.amazon.com / kdp.amazon.co.jp) | 一部取得可 |

→ 以下、**「数字つきの一次情報」「実在タイトル」「推測・一般論」を明示的に区別**して書く。確認できないものは「確認できず」と明記する。

## 0. 前提: 2026年に起きた環境変化(これを知らずに戦略を立てると外す)

### 0-1. Kindle Unlimited → **「Kindle+(キンドルプラス)」に名称変更**(2026年10月22日)

- 変更日: 2026年10月22日。利用規約も10月21日付で「Kindle+ 利用規約」に差し替え。
- 変わったこと: **名称とデザインのみ**。読み放題冊数の表記が「500万冊」→「数百万冊」に変更。
- 変わらないこと: 月額980円(税込)、初回30日無料、同時20冊、会員の手続き不要。
- **KDP著者への影響**: KDPヘルプに「KDPセレクトに登録すると、Kindle+ でロイヤリティを獲得できます」と記載。**独占条件・90日登録期間・KENP(既読ページ)に応じた分配の仕組みは変更なし**。登録済み電子書籍は手続きなしでKindle+対象のまま。
- 米国では、KDPセレクト登録の**オーディオブック**が追加料金なしで聴けるようになった(聴かれたページ分の分配あり)。**日本は未対応・開始時期未発表**。KDPヘルプは日本語のデジタルボイスを「現時点では、日本語はサポートされていません」としている。
- 出典: https://ebook-wisdom.com/information/kindle-unlimited-renamed-kindle-plus / https://manga-sub-navi.hatenablog.com/entry/2026/10/23/152951 / https://popposblog.com/kindle-plus/
- **本プロジェクトへの示唆**: 本文・商品説明・SNS告知で「Kindle Unlimited」と書くと古い表記になる。**「Kindle+(旧Kindle Unlimited)」表記が安全**。ただし読者の検索語としては「Kindle Unlimited」「読み放題」がまだ主流と推測されるため、キーワード欄では併記を検討。

### 0-2. KDPの出版ペース制限が**週2タイトル/フォーマット**に(公式確認済み)

- KDP公式ヘルプ(英語)原文: **"2 titles per book format each week"**。日本語版は「1週間に同時に作成できるタイトル数を、本のフォーマット(電子書籍および紙書籍)ごとに2点まで」。
- 「作成数の上限」と「初回提出数の上限」は**別枠**で管理され、**フォーマット別(eBook / paperback / hardcover)**にそれぞれ適用。リセットは**毎週日曜 0:00 UTC**(日本時間 日曜9:00)。
- 既に提出済みタイトルの**改訂はカウントされない**。
- かつての「1日3冊」(2023年9月導入、生成AIによる粗製乱造対策)は現行ルールではない。変更時期は二次情報では2026年9月21日とされるが**公式には未確認**。
- 出典(公式): https://kdp.amazon.com/en_US/help/topic/G202172740 / https://kdp.amazon.com/en_US/help/topic/G201857950
- 出典(経緯): https://internet.watch.impress.co.jp/docs/yajiuma/1533950.html / https://note.com/o_chan_1998/n/n0022079499b4
- **示唆**: 「短編を大量に量産して点数で稼ぐ」戦略の上限が物理的に下がった。**1冊あたりの完成度とシリーズ設計で勝つ時代**になっている。本プロジェクトの方針(1冊を作り込む)と整合する。

### 0-3. AI生成コンテンツの申告義務と審査厳格化

- AI生成コンテンツ(テキスト・画像・翻訳)の申告は2023年後半から必須。申告漏れは**本の削除・アカウント停止・印税没収**につながる可能性が指摘されている。
- AIフラグが付いた本、特に画像中心の本には、より厳しい品質審査が行われるという報告がある(**公式発表の裏付けは確認できず**)。
- 出典: https://note.com/idhica/n/n74fba7e3436e / https://aiwritebook.com/ja/blog/ai-generated-books-amazon-legal/

### 1-2. 「有料ランキングにKU本が多い」説の検証状況

- 電子書籍出版ラボの検証記事は、**KU対象本は「購入数＋読まれたページ数(KENP)」で、対象外本は「購入数」のみ**でランキングに反映されると整理し、2018/11/13時点で**有料上位20作のうち19作がKU対象本、上位100作のうち対象外は15作程度**だったと報告している。
  - 出典: https://publish-e-books.com/toll-ranking-unlimited/
  - **重大な留保**: これは**2018年のデータ**。上記1-1で確認した現在の顔ぶれ(大手の話題作・マンガ)と整合しない。**この構成比を2026年にそのまま当てはめるのは危険**。
- 一方、KENPがランキングに影響するという点自体は、複数の個人出版者が実データで裏付けている(→2-1)。

## 2. KU(読み放題/Kindle+)で強いジャンル: 「次々読む」のはどこか

### 2-1. KENPはランキングを「維持」する。販売は「押し上げる」

一級建築士でKindleベストセラー著者のだいだい氏が、自身の実データで整理している:

- **「購入(販売)は順位を一気に押し上げ、KENPは順位を維持する力になる」**
- 自身の1冊目: **その月の販売数は2冊だが、KENPは18,000ページ/月**。これだけでベストセラー表示を再獲得。
- 5冊目は売れ筋ランキング5部門で1位。
- 無料キャンペーンは**無料ランキングにしか反映されず、有料ランキングには直接影響しない**。レビュー獲得と終了後の仕込みとして機能する。
- 2026年の傾向(**著者の推測**): AIによる出版数急増で供給が増えたため、Amazonは販売数だけでなく**読了率・著者フォロー数・読者との継続的関係**といったエンゲージメント指標をより重視していると見られる。
- 出典: https://note.com/daidaidesign/n/nf3e54d7de721

→ **KU対策 = ランキング維持 = 露出の持続**。個人出版はKDPセレクト登録がほぼ必須。

### 2-2. 実測: 販売とKENPの比率(mamou氏・伝統工芸20冊)

| 本(テーマ) | 累計販売 | 販売の印税 | KENP(読み放題ページ数) |
|---|---|---|---|
| 螺鈿入門 | 57冊 | 2,076円 | 3,451 |
| 組子入門 | 46冊 | 1,472円 | 2,361 |
| 螺鈿の貝の本 | 16冊 | 512円 | 660 |
| 金継ぎ入門 | 12冊 | 384円 | 1,037 |
| 勾玉 | 4冊 | 128円 | **1,582** |

- **収益の約46%がKENP、約54%が販売**。
- 『勾玉』は**販売4冊でもKENP 1,582ページ**で、『金継ぎ入門』(1,037)を上回った。→ **冊数だけでは読まれ方が分からない**。
- 値上げテスト(螺鈿入門・1冊): 99円(印税率35%)で6週間=7冊/224円 → 250円(印税率70%)で6週間=**8冊/1,264円**。冊数ほぼ同じで印税約5.6倍。
- 確定印税累計: 2024年12月〜2026年8月で**8,773円**。最高月は2026年3月の1,684円。
- 出典: https://mamou.biz/kindle-best-selling-genre/ / https://mamou.biz/kindle-publishing-income/
- **留保**: 著者1人・全て伝統工芸という狭い条件。**ジャンル間の優劣の証明ではない**。かつ**ニッチ特化は「読まれるが稼げる額は小さい」ことを示すデータでもある**。

### 2-3. 「次々読む」が実在するジャンル: 小説・ラノベのシリーズ

KDPで25冊小説を出した著者(dxlontheroad)の報告が最も具体的:

- **「1巻から2巻への購入の流れが想像以上に多く、特にKU読者でその傾向が強い」**
- **「KUの読者は作者単位で読み進めることが多く、作品数が揃っていると既読ページ数(KENPC)が積み上がりやすい」**
- 初期2作は売上ほぼゼロ。**「1作では判断できない。10〜20作書いて初めて売れるかの見当がつく」**
- タイトル・キーワード・あらすじに**検索でヒットする語**を入れることが重要。検索経由の読者は継続購入し、他作品にも流れる。
- 表紙は文字だけでも売れている作品がある。絵の表紙への差し替え効果は不明瞭。**作品数や検索ワードほど重要ではないかもしれない**。
- Kindleの**シリーズページ**が作られ、他作者のシリーズページからリンクされる可能性がある。
- 出典: https://novel.dxlontheroad.com/2023/12/03/amazon_kdp_publish/

兼業ラノベ作家わんた氏は**約2年でKDP累計収入1,000万円超**を報告。新シリーズ1巻が発売数か月後にKENPの伸びで浮上し、**SF・ホラー・ファンタジーカテゴリで1位**を取った例も報告している。
- 出典: http://wantablog.com/?p=1414 / http://wantablog.com/?p=2751 (**本文取得は503で失敗。スニペットのみ**)

一方、恋愛小説については Yahoo!知恵袋で「KDPで恋愛小説を出している知人は**月に1冊売れれば良い方**」という回答がある(個人の体験談、一般化不可)。
- 出典: https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q12314636082

### 2-4. KU全体で「まとめ読み」需要が大きいのはマンガ・ラノベ(ただし大手の棚)

- KU(Kindle+)で**全巻読み放題の完結マンガ**(『きまぐれオレンジ☆ロード』全10巻、『ラブひな』全14巻など)、ラノベ(『私の推しは悪役令嬢。』全5巻、『とらドラ！』全10巻、『冴えない彼女の育てかた』全18巻)が「まとめ読み」需要の中心。
- ただし**シリーズの1巻だけが対象**のケースも多い(例: 『負けヒロインが多すぎる！』は1巻のみ)。
- 出典: https://www.rere.jp/360082/ / https://unlimichannel.com/kindleunlimited_lightnovels/ / https://popposblog.com/kindle-plus-osusume/
- **示唆**: 「次々読む」最大のボリュームゾーンは**大手のマンガ・ラノベ**であり、個人出版が直接競合できる場所ではない。個人出版が「次々読む」を作るなら、**自分の作品群の中で回遊させる**(同一テーマで2冊目、シリーズ名の統一)しかない。

### 2-5. KUと相性が良いと**複数ソースで一致して**言われているジャンル

- 実用書全般(レシピ、家計管理、時短術、資格入門、副業) ← 紙だと1冊1,200円以上するものが読み放題で読めるため、気軽に手に取られる
- 自己啓発、生活実用、スピリチュアル、エッセイ、ビジネス書
- 出典: https://www.luft.co.jp/media/se-it-without-losing-anything/ / https://publish-e-books.com/k-read-many/ / https://shuppan-lab.com/kindle-unlimited-kdp-select-guide/
- **留保**: いずれも著者見解。**ジャンル別のKENP統計は公開されておらず、確認できず**。

### 2-6. KUに向かないケース(実データ)

- かくじん氏の『統計検定(R)準１級非公式参考書』は**紙で買われることが多かったためKU非登録・売り切り**。
  → **資格・専門書で「手元に置きたい」本は、KUに入れないほうが収益が高い場合がある**。

## 3. 個人出版で成功しているテーマの共通点

複数の一次情報を突き合わせると、以下の5要素に収束する。

### (A) 当事者性 × 「情報が存在しない」こと
> 「当時Google検索しても情報が少なく、見つかるのは医療用語だらけの仕組みの解説ばかりだった。体験ベースのコミックエッセイに需要があった」
> — 脳脊髄液減少症のコミックエッセイ(月2〜3万円の印税)
> 出典: https://note.com/toyotoyotoyo/n/n49476f0082dd

同著者が「今後読まれそう」と挙げた題材: **ブラック企業、コロナにかかった話、嫁姑問題、復讐した話**。

### (B) ニッチの絞り方が「カテゴリ」ではなく「病名・資格名・手続き名」レベル
> 「『がん』より『悪性リンパ腫』と限定したことでライバルが減った」

出典: https://library.libecity.com/articles/01KK1M83P0D567RQ94GWDB7WZM

### (C) 「体験記」単体ではなく「体験記 × 解決手順」
これは**最も重要かつ、最も意見が一致している点**。

- mamou氏の実データ: 売れたのは**「入門」がタイトルに入った本**(螺鈿入門57冊、組子入門46冊)。同じ素材でも解説型の『螺鈿の貝の本』は16冊。**読み物・エッセイ型は90日間ほぼ0冊**。
- clear氏(14冊以上出版)が挙げる「売れない本の穴❸」: **「著者の体験談だけで、読者が得られるものがない本=ただの日記」**。
  出典: https://note.com/clear0308/n/n83a3e2da28af
- かくじん氏の**最も読まれなかった本**は処女作『結局、どの健康法が良いの？』。本人の分析:「**素人の体験談は求められにくく、医学系は権威性・信頼性が重視される**」。
- 一方で**成功している当事者本はすべて「手続き」「対処」が入っている**: 『離婚するまで調停と裁判で５年４か月かかった話』(手続きの実録)、『発達障害グレーゾーンの私が仕事も家庭も回せるようになった時間管理術』(方法論)、『借金完済への６ステップ』(手順)。

→ **公式: 当事者性(信頼) × 具体的手順(効用) × 固有名詞レベルのニッチ(検索独占)**

## 4. 「悩みの深さ」が強いテーマ(実際に本が存在し読まれているもの)

### 4-1. 本プロジェクトのYMYL制約との関係(重要)

本プロジェクトは医療・法律・投資の**助言**は扱えない。だが上記の実例は、**助言ではなく「体験記+手続きの実録」として書かれている**。書ける範囲は次のとおり:

| 書けること(実例で確認済み) | 書けないこと |
|---|---|
| 「調停が何回あり、何を聞かれ、何を準備したか」の時系列実録 | 「あなたのケースでは〇〇すべき」という法的助言 |
| 「診断されてから生活のどこが困り、どう工夫したか」 | 診断・治療法の推奨、効果の断定 |
| 「個人再生の申立てで実際に提出した書類と期間」 | 債務整理の方法の選択を勧める |
| 「介護保険の窓口で何を言われ、どう動いたか」 | 制度の解釈を断定する |
| **各章末に「必ず専門家(弁護士/医師/ケアマネ)に確認を」と明記** | — |

→ **「当事者の実録 + 読者が次に取るべき行動の整理 + 専門家への接続」**という構成なら、YMYL領域の「悩みの深さ」を安全に取れる。これが**本プロジェクトの最大の勝ち筋**。

## 5. 当事者本・体験記の市場

### 5-1. 個人出版と相性が良い理由(実データで言えること)

1. **一次情報は複製できない**。AI量産本との差がここでしか出ない(0-3のAI審査厳格化と合わせると、2026年はこの価値が上がっている)
2. **検索需要が狭く深い**。「悪性リンパ腫 闘病記」を大手は出さないが、診断された人は必ず検索する
3. **大手が出さない理由がある**。部数が見込めない=個人出版の独占領域
4. **更新できる**。かくじん氏は『悪性リンパ腫闘病記』を**定期的に内容更新**している。電子書籍のみの強み
5. **情報の信頼性への不安がWebから書籍へ読者を押し出す**。とよとよ氏の分析:「Webの医療情報には信頼性への不安があり、専門的な情報は書籍から探す人が多いのではないか」

### 5-2. ただし「体験談だけ」は失敗する(3-(C)の再掲)

- かくじん氏の最も読まれなかった本が健康法の体験談だった事実
- mamou氏の「読み物・エッセイ型は90日間ほぼ0冊」
- clear氏の「ただの日記」指摘

→ **当事者本の勝ちパターンは「体験記」ではなく「体験に裏打ちされた手引き」**。タイトルに「入門」「〜する方法」「〜ステップ」「〜ガイド」が入っている本が実際に売れている。

### 5-3. 形式としての当事者本: コミックエッセイの実例数値

脳脊髄液減少症のイラストコミックエッセイ(とよとよ氏):
- 形式: **1ページに4コマ漫画1つ、60ページ以上**。元は妻のブログを再編集
- 価格: 300円(報酬200円になるよう設定)
- KU: 1ページあたり約0.5円
- 実績: **2冊で月2〜3万円前後**の印税 → 約3年後に月5,000円程度に
- 英訳版はほぼ読まれなかった
- 注意: 漫画の複数社投稿サービス「no.9」は**KU(KDPセレクト)と併用不可**

### 6-2. 「飽和しているニッチ」= 入ってはいけない場所

かくじん氏の実データで、**同じ著者の中で最も読まれなかった**カテゴリ:

→ **「Kindle出版」「副業」「自己啓発」は個人出版者自身が最も多く書いている領域で、最も読まれない**。これは複数ソースで一致する。

## 7. 形式の工夫: 売れやすい形の傾向

### 7-1. タイトルに「形式」を明示する(実データあり)

上野ナツ氏(KDPで日給1万円達成)の実践:
- **「会話形式」「小説で学ぶ」「図解」といった形式をタイトルに明示**
- 長いサブタイトルに関連キーワードを多く含める
- 3冊とも**8万字超の長編**。図解を多く入れてページ数を増やし、**KENPC(読み放題の換算ページ数)を底上げ**
- 達成日の内訳: 注文7冊 + KENP約17,500ページ。価格は780円・780円・580円
- KENPC約350の本なら、1冊完読で**1ページ0.4円 × 350 = 約140円**
- 達成日の総合順位は394位・1,236位・3,424位 → **高単価・高ページ数なら、順位がもっと低くても達成可能**
- 出典: https://note.com/natsu_vt/n/n85e48ccc45f6

### 7-2. 分量の目安(ソースで幅がある)

| ソース | 目安 | 文脈 |
|---|---|---|
| clear氏 | **10,000〜15,000字**(章立て・事例・まとめ込み) | 実用書の最低ライン |
| 一般的助言 | 最低100ページ(約1万文字) | — |
| 短編量産型 | 1冊15,000〜20,000字を99円で19冊積み上げ | **週2タイトル制限で現在は実行困難** |
| 上野ナツ氏 | **8万字超** | KENPCを稼ぐ戦略。高価格(580〜780円)と両立 |

→ **KENP収益を狙うなら長い方が有利。だが薄い長文はレビューで叩かれる**。「図解・事例・ワークを入れて厚くする」が両立の答え。

### 7-3. 完読率を上げる構成(KENPに直結)

- **章を細かく区切り、小見出しを入れることで完読率とKENPが伸びた**という報告
- 小説では「読み始めて合わなければすぐ別の本に移るため、**早めに事件を起こす**」
- 出典: https://shuppan-lab.com/kindle-publish-how-to-earn/ / https://note.com/bright_llama430/n/nca36ef12e30f

### 7-4. 形式別の確認状況

### 1位. カスタマーハラスメント対応(職種別・立場別のシリーズ展開)
- **根拠**: 2026年10月1日に**全事業主へ義務化**(猶予なし)。厚労省指針は2026年2月告示。制度施行直後で需要ピーク。本プロジェクトは既に知識資産(facts-kasuhara)とbook02を保有。
- **狙い方**: 「カスハラ対策」という大テーマではなく、**「小売店の店長のための」「コールセンター担当者のための」「相談窓口担当者のための」**に分割してシリーズ化。6-1の「固有名詞レベルのニッチ」原則の適用。
- **リスク**: 大手が追随する速度が速い領域。先行の2〜3ヶ月が勝負。

### 2位. 離婚・モラハラの「手続き実録」
- **根拠**: 『離婚するまで調停と裁判で５年４か月かかった話』『実録 理不尽な離婚までの道のり』(5部作)が実在。レビューが「これから調停を控える読者」から入っている=**今まさに進行中の読者が買う最深の悩み**。シリーズ化の実績あり。
- **YMYL対応**: 「調停が何回あり、何を準備し、何を聞かれたか」の時系列実録。法的助言ではなく手続きの体験記として成立。各章末に弁護士相談への接続を明記。
- **狙い方**: 「離婚」ではなく「**調停**」「**別居**」「**親権**」「**婚姻費用**」の手続き単位で分冊。

### 3位. 親の介護・認知症(当事者家族の実録シリーズ)
- **根拠**: 「認知症の家族介護で心を壊さないシリーズ」(くろふく)、「孤独の介護シリーズ」(なおすけ)という**個人著者のシリーズが既に成立している**=読者が続けて読む証拠。介護カテゴリは大手も強いが、大手は「入門書」(『親不孝介護』『親の介護をする前に読む本』)で、**「ひとりで介護している人の心の消耗」という角度は個人の独占**。
- **狙い方**: 「介護」ではなく「**遠距離介護**」「**きょうだいと折り合わない介護**」「**要介護認定の申請でつまずいた話**」。

### 4位. 発達障害・グレーゾーンの当事者 × 具体的対処法
- **根拠**: 「発達障害グレーゾーン実体験」シリーズ(5巻)が実在し、前島ふみ氏の本は**レビュー46件**(個人出版としては多い)。かつ**売れているのは『…時間管理術』(方法論型)**で、3-(C)の「体験記×解決手順」公式に完全一致。
- **狙い方**: 「発達障害」ではなく「**グレーゾーン**」「**診断がつかなかった人**」「**40代で気づいた**」「**事務職で詰む場面**」のレベルまで絞る。
- **YMYL対応**: 診断・治療には触れず、「生活と仕事の工夫」に限定。

### 5位. 特定の病名・症状の闘病&生活実録(情報が存在しない疾患を選ぶ)
- **根拠**: 『悪性リンパ腫闘病記』(「がん」から絞って勝った)、脳脊髄液減少症のコミックエッセイ(**月2〜3万円**、Kindle内検索+Google検索が主流入)。かくじん氏は本を**定期的に更新**している。

### 6位. おひとりさま終活・デジタル終活
- **根拠**: 「おひとりさま終活シリーズ」(ようこ)、『おひとりさまの老後不安をなくする法則：経済不安と**孤独死**を防ぐ』(桑田暁美)、『50代の終活 エンディングノートから始める終活5ステップ』が実在。大手の終活本は**1,617円帯**で、個人出版が300〜780円に置けば価格優位。「デジタル終活」という新しい切り口が立ち上がり中。
- **狙い方**: 「**スマホとサブスクの終活**」「**ひとり暮らしの入院準備**」「**身元保証人がいない場合の手続き**」など、**大手の終活本が扱わない具体的場面**。

### 7位. 資格・専門分野の「非公式参考書」(ニッチな試験・科目)

### 8位. 借金・債務整理の「手続き実録」
- **根拠**: 『借金は悩んでも解決しない！債務整理体験記』4.8(5件)、『元弁護士が多額の借金で個人再生をした体験談』3.7(9件)、『借金総額1700万円！？…3年で完済した**6ステップ**』が実在。著者名を「多重債務者だった夫婦」にするほど当事者性が商品価値。
