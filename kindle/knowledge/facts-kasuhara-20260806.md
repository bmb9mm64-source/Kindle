## 1. カスタマーハラスメントの定義（厚生労働省）

### 確認できた事実

- 厚生労働省は「カスタマーハラスメント対策企業マニュアル」等を作成しており、実在する。作成・公表は2022年（令和4年）2月。「顧客等からの著しい迷惑行為（いわゆるカスタマーハラスメント）の防止対策の一環」として、マニュアル本体・リーフレット（概要版）・啓発ポスターが作られている。
  - 出典: 厚労省ハラスメント対策ポータル「あかるい職場応援団」 https://www.no-harassment.mhlw.go.jp/foundation/harassment_list/customer-hara
  - 出典: 業種別マニュアル例（スーパーマーケット業向け、公式PDF） https://www.no-harassment.mhlw.go.jp/assets/pdf/cusuhara_manual_super.pdf
- マニュアルにおけるカスタマーハラスメントの考え方（企業へのヒアリング等を踏まえた整理）:
  「顧客等からのクレーム・言動のうち、当該クレーム・言動の要求の内容の妥当性に照らして、当該要求を実現するための手段・態様が社会通念上不相当なものであって、当該手段・態様により、労働者の就業環境が害されるもの」
  → **「要求内容の妥当性」と「手段・態様の社会通念上の相当性」の2軸**で捉える枠組み。
- 改正法（下記2.）における「職場におけるカスタマーハラスメント」の3要素:
  ①顧客、取引の相手方、施設の利用者その他の事業主の行う事業に関係を有する者（顧客等）の言動であって、②社会通念上許容される範囲を超えたものにより、③労働者の就業環境が害されるもの（3要素をすべて満たすもの）。電話やSNS等インターネット上の言動も含まれるとされる。
  - 出典: 政府広報オンライン「カスハラとは？法改正により義務化されるカスハラ対策の内容…」 https://www.gov-online.go.jp/article/202510/entry-9370.html
  - 出典: 厚労省リーフレット「令和8年10月1日からハラスメント対策が強化されます！」 https://www.mhlw.go.jp/content/11900000/001662576.pdf

### 本文で使ってよい表現の例

- 「厚生労働省の資料では、カスタマーハラスメントは大まかに言うと『要求の内容が妥当か』『要求を通すためのやり方（手段・態様）が社会通念上おかしくないか』の2つの軸で捉えられています」
- 「同じ『返金してほしい』という要求でも、内容に理由があり、伝え方も常識の範囲なら正当なクレーム。内容に無理があったり、暴言・長時間の拘束・土下座の強要のようなやり方に及べば、それはカスハラ側に寄っていきます」（※例示の細目は執筆前にマニュアル原文で再確認）
- 「詳しくは厚生労働省の『カスタマーハラスメント対策企業マニュアル』などの公式資料をご覧ください」

### 本文で断定してはいけないこと

- 「この行為はカスハラに該当する／しない」という**個別ケースの該当性の断定**（就業環境が害されたか等は個別判断）。
- 定義の一言一句を「法律の条文」として引用すること（マニュアルの定義と法律・指針上の定義は文言が異なる。引用するなら出典を区別する）。
- カスハラをした客が「処罰される」「違法行為である」等の法的評価の断定。

## 2. 改正労働施策総合推進法（2026年10月1日施行）

### 確認できた事実

- 労働施策総合推進法等の一部を改正する法律が**令和7年（2025年）6月に成立し、6月11日に公布**された。カスタマーハラスメント対策（および求職者等へのセクハラ対策）の**雇用管理上の措置義務化は令和8年（2026年）10月1日施行**。施行期日を定める政令（令和8年政令第17号）が制定されている。
  - 出典: 厚労省リーフレット https://www.mhlw.go.jp/content/11900000/001662576.pdf
  - 出典: 厚労省「職場におけるハラスメントの防止のために」 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyoukintou/seisaku06/index.html
  - 出典: 全国商工会連合会（周知ページ） https://www.shokokai.or.jp/?post_type=sisakus&p=15597
- **義務を負うのは「事業主」**。労働者を雇用するすべての事業主が対象で、企業規模による経過措置（中小企業の猶予）は設けられていないと解説されている。
- 事業主が講ずべき措置として挙げられている内容（指針ベース）: 事業主の方針等の明確化と労働者への周知・啓発／労働者からの**相談に応じ適切に対応するための体制整備**／カスハラ発生時の事実関係の迅速・正確な確認と適正な対処（被害労働者への配慮を含む）／相談者等のプライバシー保護／**相談したこと等を理由とする不利益取扱いの禁止**。
  - 出典: 政府広報オンライン https://www.gov-online.go.jp/article/202510/entry-9370.html
  - 出典: 厚労省リーフレット https://www.mhlw.go.jp/content/11900000/001662576.pdf
- 厚労省は「事業主が職場における顧客等の言動に起因する問題に関して雇用管理上講ずべき措置等についての指針」を公表済み（複数の専門解説が告示済みと報道）。**指針の正式な告示日・告示番号は未確認**（一次資料で照合できず）。

### 労働者側から見た意味（本文の主眼）

- 義務の名宛人は会社（事業主）であり、**現場の個人が「カスハラを我慢して解決する義務」を負うわけではない**。
- 労働者は、会社に相談窓口・対応方針があるはずと期待でき、なければ整備を求める根拠になる。相談したことを理由とする不利益取扱いは禁止される方向で措置が求められている。

### 本文で使ってよい表現の例

- 「2026年10月1日から、改正労働施策総合推進法により、カスハラから従業員を守る対策（相談体制の整備など）が会社（事業主）の義務になりました」（※執筆時点2026年8月なら「義務になります」）
- 「義務を負うのはあなた個人ではなく会社です。だからこそ、一人で抱え込まず、会社の窓口・上司に引き継ぐことが制度の想定している対応です」
- 「自分の勤務先にどんな方針・相談窓口があるかは、就業規則や社内規程を確認するか、上司・人事に聞いてみてください」

### 本文で断定してはいけないこと

- 措置義務の詳細な法解釈（何をすれば義務を満たすか、違反時に会社がどうなるか等）。罰則の有無・行政指導の仕組みなどの細部は本書では踏み込まない。
- 「会社に○○を請求できる」「会社が○○しなければ違法」といった権利主張の具体的助言（弁護士業務に近づくため書かない）。
- 指針の告示日・条文番号の断定（未確認のため）。条文番号を書きたい場合は執筆前にe-Gov法令検索等で原文確認する。

## 3. 東京都カスタマー・ハラスメント防止条例（2025年4月1日施行）

### 確認できた事実

- 正式名称「東京都カスタマー・ハラスメント防止条例」。2024年10月4日に**全国初のカスハラ防止条例として成立**し、**2025年（令和7年）4月1日施行**。
  - 出典: 東京都報道発表 https://www.metro.tokyo.lg.jp/information/press/2025/03/2025032804
  - 出典: TOKYOはたらくネット（条例・指針・Q&A掲載ページ） https://www.hataraku.metro.tokyo.lg.jp/plan/kasuhara_jourei/index.html
  - 出典: 条例本文（東京都例規集） https://www.reiki.metro.tokyo.lg.jp/reiki/reiki_honbun/g101RG00005328.html
- 定義（条例第2条第5号）: カスタマー・ハラスメントとは「顧客等から就業者に対し、その業務に関して行われる著しい迷惑行為であって、就業環境を害するもの」。
- 「**何人も、あらゆる場において、カスタマー・ハラスメントを行ってはならない**」という禁止規定を置く（都のQ&A・解説で第4条とされる)。
- **罰則はない**（理念型の条例。都のQ&A等で罰則を設けない趣旨が説明されている）。
  - 出典: 東京都Q&A（PDF） https://www.hataraku.metro.tokyo.lg.jp/plan/kasuhara_qa_2025_0328.pdf
- 条例の適用に当たっては、**顧客等の権利（正当なクレーム等）を不当に侵害しないように留意する**旨の規定がある。都・顧客等・就業者・事業者それぞれの責務を定め、事業者には手引の作成等の努力義務がある。カスハラ防止指針（ガイドライン）・各団体共通マニュアルも都が策定している。
  - 出典: 東京都報道発表（指針策定） https://www.metro.tokyo.lg.jp/information/press/2024/12/2024122511
  - 出典: 東京都報道発表（共通マニュアル） https://www.metro.tokyo.lg.jp/information/press/2025/03/2025030410

### 本文で使ってよい表現の例

- 「2025年4月には、全国で初めて東京都で『カスタマー・ハラスメント防止条例』が施行されました。罰則はありませんが、『何人もカスハラを行ってはならない』と明記されたことは、働く人を守る方向への大きな変化です」
- 「この条例は正当なクレームまで禁じるものではなく、顧客の正当な権利を不当に侵害しないよう留意することも定められています」

### 本文で断定してはいけないこと

- 「条例違反だから処罰される・訴えられる」等の帰結の断定（罰則はない）。
- 東京都以外にも同種条例（北海道・三重県桑名市等が報じられている）があるが、**本パックでは他自治体の条例は未確認**。書くなら「他の自治体にも広がりつつある」程度に留めるか、個別に裏取りする。
- 条例の条文番号の断定は、執筆前に条例本文（上記例規集URL）で最終確認してから。

## 4. 公的な相談窓口

### 確認できた事実

- **総合労働相談コーナー**（正式名称）: 厚生労働省の都道府県労働局・労働基準監督署内等に設置。**予約不要・無料**で、職場のあらゆる労働問題（いじめ・嫌がらせ等を含む）を相談できる。面談または電話。
  - 出典: 厚労省 総合労働相談コーナーの所在地案内 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/location.html
  - 出典: 厚労省スタートアップ労働条件サイト https://www.startup-roudou.mhlw.go.jp/soudan.html
- **警察の使い分け**:
  - **110番** = 今すぐ警察官に駆けつけてほしい緊急の事件・事故の通報（暴力・身の危険など）。
  - **警察相談専用電話「#9110」** = 緊急対応までは要らないが警察に相談したいことがある場合。全国どこからでも、かけた地域を管轄する警察本部等の相談窓口につながる。受付は平日8:30〜17:15が基本（都道府県により異なる）。
  - 出典: 政府広報オンライン「警察に対する相談は警察相談専用電話『＃9110』番へ」 https://www.gov-online.go.jp/article/201309/entry-7508.html
  - 出典: 警視庁「警察相談ダイヤル#9110」 https://www.keishicho.metro.tokyo.lg.jp/jiken_jiko/110/110_9110.html

### 本文で使ってよい表現の例

- 「社内に相談先がない・機能していない場合は、国の『総合労働相談コーナー』（各都道府県労働局・労働基準監督署内、無料・予約不要）が使えます」
- 「暴力を振るわれた・『殺すぞ』などの脅迫を受けたなど身の危険を感じる場面では、ためらわず110番。緊急ではないが警察に相談したいことは #9110（警察相談専用電話）へ」

### 本文で断定してはいけないこと

- 「この程度なら通報すべき／すべきでない」という**通報基準の独自ノウハウ**（骨子の方針どおり「ためらわず110番・上司へ」以上は書かない）。
- 相談窓口の受付時間・体制の細部の断定（変わりうる。「最新情報は公式サイトで」と誘導する）。
- 「警察が必ず動いてくれる」「相談すれば解決する」等の結果の保証。

## 5. 正当なクレームとカスハラの違い（公的資料の考え方）

### 確認できた事実

- 厚労省マニュアルの枠組み（上記1.）: クレームがすべてカスハラなのではなく、**「①要求内容の妥当性」×「②手段・態様の社会通念上の相当性」**で判断する。要求内容に妥当性がある場合でも、手段・態様が社会通念上不相当（暴力・脅迫・長時間拘束など）ならカスハラになりうる、という整理。
  - 出典: https://www.no-harassment.mhlw.go.jp/foundation/harassment_list/customer-hara
- 東京都条例も「顧客等の権利を不当に侵害しないように留意」と規定し、**正当なクレームとカスハラを区別する**立場（上記3.）。
  - 出典: https://www.metro.tokyo.lg.jp/information/press/2025/03/2025032804
- 「社会通念上許容される範囲を超えた言動」かどうかが法律上の定義でも中核（上記2.の3要素の②）。

### 本文で使ってよい表現の例

- 「クレーム＝悪ではありません。商品やサービスへの正当な指摘は、お店を良くしてくれる大切な声です。公的資料でも、正当なクレームとカスハラははっきり区別されています」
- 「目安はシンプルに2つ。『言っている内容に理があるか』『言い方・やり方が常識の範囲か』。内容に理があっても、暴言・長時間の拘束・土下座の強要のようなやり方になったら、それはもうクレームではありません」（※例示は執筆前にマニュアル原文の例示一覧と照合）
- 「最終的な線引きは会社の方針・規程によるので、勤務先のルールを確認しておきましょう」

### 本文で断定してはいけないこと

- 具体的な行為の該当性判定リストを「これはカスハラ、これはセーフ」と本書独自に断定すること（マニュアルの例示を紹介する形に留め、出典を示す）。
- 「○分以上の電話は不当」「○回目の来店要求はカスハラ」など、公的資料にない数値基準の創作。
- 損害賠償・出入り禁止・威力業務妨害等の法的措置に関する助言(「〜できます」と書かない。「会社・警察・弁護士等の専門窓口へ」で止める)。
