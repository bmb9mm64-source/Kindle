# 月10万円の再設計(確定版)

- 作成日: 2026-11-22
- 経緯: 既刊3冊の売上ゼロ → 診断4本 → 候補8案 → 批判検討3本 → 「本を増やす路線」が否定される
  → 前提の再設計3本(収益モデル/スキル収益化/既存資産)
- 根拠ファイル: knowledge/ 配下の 20261122 系9本

---

## 結論を先に

**月10万円は「コンテンツを売る」だけでは届かない。「制作能力を売る」のが本線になる。**

既刊3冊は商品としては失敗したが、**制作能力の証明としては成立している**。
買い手が欲しいのは「ベストセラー実績」ではなく「本を形にする能力」であり、
売上ゼロでも3冊完成させた事実はそのまま営業材料になる。

これが今回の再設計の核心である。

## なぜそうなるか(3本の統合)

### 事実1: コンテンツ販売は単価が低すぎる

| 置き場所 | 1本/1部の手取り | 月10万円に必要な量 |
|---|---|---|
| Kindle(70%・480円) | 207〜305円 | 月328〜483部 |
| note 有料記事(実用ノウハウ系) | 約1,575円 | 月約64本の販売 |
| **現場業務文書の制作代行** | **1ページ6,000〜15,000円** | **月7〜17ページ(10〜20時間)** |

note公式が約30万件を分析した一次データで、実用ノウハウ系の売上上位20%の平均価格は1,842円、
手取り率85.5%。Kindleの7.6倍の単価。ただし**流入はGoogle検索が約7割、note内の回遊は1割未満**で、
「置けば見つかる」わけではない。

### 事実2: 冊数では露出が生まれない(実測)

先行者「くらしの制度ガイド編集部」が17冊を4か月投下して**レビュー0・ランキング圏外**。
Kindle個人出版の中央値は**10〜20冊で月1,000〜2,000円**(20冊→累計8,773円/約2年の実測あり)。
**既刊3冊・売上ゼロは失敗ではなく平均的な初期状態。**

### 事実3: 3つの資産が同時に効く経路が1つだけある

- AI編集パイプライン(速度)
- 営業・接客・販売の現場経験(内容の正しさ)
- 3冊の完成実績(成果物の提示)

この3つが同時に効くのは**「現場業務文書のAI制作代行」**のみ。
単価はSEO記事の3〜6倍(業務マニュアル原稿 1ページA4≒1,000字で6,000〜15,000円)。
現場マニュアルは制作会社が最も苦手で、AI単体では絶対に埋まらない領域。

公的調査も支持する: 中小企業のAI導入率は営業・販売・サービス部門で60.3%、
最大の障壁は「具体的な活用場面が不明」35.6% = 技術ではなく**業務翻訳の問題**。

### 事実4: 市場は「量」から「単価」へ移っている

クラウドワークスのライティング案件数は2021→2025年で**−46%**、平均単価は**+11%**。
文字単価1.6円の案件に**310人応募・契約0**。量を取る戦略は死につつある。

## 3層ポートフォリオ

### 第1層: キャッシュを作る(成果物を売る) ← 本線

**現場業務文書のAI制作代行**
- 接客マニュアル / 営業トークスクリプト / 研修教材 / 業務手順書
- 単価: 1ページ6,000〜15,000円。月10万円 = 月7〜17ページ = 10〜20時間
- 立ち上がり: 初受注3〜6か月、月10万円 9〜18か月
- 入口: ココナラ出品 → 実績を作って直取引へ

**Kindle出版代行(併走)**
- ココナラ実勢: 基本2万〜5万円、執筆込み6万〜9万円
- **3冊の実績が売上ゼロでも通用する唯一の経路**
- AI利用開示を売りにする出品が既に成立している
- 注意: 納品物にAI申告判定書を同梱する(顧客側に申告義務が発生するため)

### 第2層: 資産を積む(コンテンツを売る)

**note 有料記事** — 単価がKindleの7.6倍。文字数と売上の相関はほぼゼロ(-0.023)なので長く書く必要はない。
「経験や知識を体系化している人」に売上が発生する(note公式)。

**Kindle既刊3冊の入口改善** — 新規執筆ではなくメタデータ改訂のみ。流通を持つ唯一の資産なので捨てない。
**KDPセレクトは外さない**(日本では外すと70%→35%に半減。KDP公式で確認)。

### 第3層: つなぎ(時間を売る) ← 必要なときだけ

**業務委託マッチング**(シューマツワーカー等)— 公式案件に「週5〜10時間で月8万〜15万円」が実在。
構造的に月10万円に最も近いが、**時間を売るモデルなのでAIパイプラインの価値が換金されない**。
定例が平日日中なら本業と衝突する。**立ち上げ期のつなぎとしてのみ使う。**

## 実行順序

### 今週(〜11/29): 著者のみ・4件。これが終わるまで編集部は何も作らない

1. **KDPレポートの実数取得**(45分) — 表示回数/無料DL/販売部数/KENP既読ページ/無料キャンペーン残日数
2. **著者セントラル登録**(30分) — Amazon広告の利用資格の前提
3. Amazonで競合上位20冊のレビュー件数とカテゴリを目視(本環境は503で不可)
4. 勤務先の**兼業規定の確認** — 副業容認企業は52.3%。業務委託型の方が通りやすい傾向

### 1〜4週: 診断を確定させる

- book02のタイトル・キーワード・カテゴリ改訂(編集部4時間 → 著者のKDP作業25分)
- 無料キャンペーン5日
- **Amazon広告 日300円×14日=4,200円**(稼ぐためではなく答えを買うため)
  - 表示1,000回未満 → この棚は金を払っても入れない
  - 表示あり・CTR0.3%未満 → 表紙で負けている
  - クリックあり・売上0 → 説明文か価格で負けている
  - **CPC50円超 or 累計1万円で必ず止める**
- ココナラに「現場業務文書の制作代行」「Kindle出版代行」を出品(既刊3冊を実績として提示)

### 2〜3か月
- 広告レポートを分岐表で読む(最大の分岐点)
- book03・book01の改訂
- note有料記事を試す(事実パックの転用ではなく、現場経験の体系化を売る)

### 3〜6か月

## 正直な見通し

- **月10万円は副業の上位20〜25%**(副業者の月収は5万円未満が約4割)。簡単ではない。
- **最短経路は第1層(代行業)で、立ち上がりに初受注3〜6か月・月10万円まで9〜18か月。**
- コンテンツ販売(第2層)は単独では月10万円に届かないが、**第1層の営業材料として機能する**。
  既刊3冊とnote記事は「この人は書ける」の証明になる。
- Kindleは捨てない。流通を持つ唯一の資産であり、改訂コストは1冊あたり数時間と小さい。
  ただし**主軸ではなく資産として扱う**。

## 捨てたもの

- 25冊シリーズ計画(冊数で露出は生まれないという実測により破棄)
- 多プラットフォーム展開(日本ではKDPセレクトを外すと70%→35%)
- 無料記事でのSEO流入を本線に置く案(AI Overviewsの影響。漏斗計算で月915円)
- 「当事者性で勝つ」という差別化軸(このニッチでは参加費であり優位ではない)
