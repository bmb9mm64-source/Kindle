# ニーズ発掘リサーチ: 読者の生の声 (2026-11-22)

## 0. 調査手法と制約(先に正直に明記)

### 使えた情報源
| 情報源 | 状態 | 使い方 |
|---|---|---|
| Yahoo!知恵袋 検索 (chiebukuro.yahoo.co.jp/search?p=...) | **取得成功**。質問タイトル・本文スニペット・総件数・閲覧数・回答数まで読めた | 本調査の主軸。実際の書き込みをそのまま確認 |
| Google サジェスト API (suggestqueries.google.com) | **取得成功** | 検索需要の手がかり(課題6) |
| はてなブックマーク検索 (b.hatena.ne.jp/q/...) | **部分的に成功** | ブクマ数=関心の強さの代理指標 |
| 楽天ブックス検索 (books.rakuten.co.jp/search) | **取得成功**。「全○件」が取れる | 「本の少なさ」の代理指標 |
| 厚労省・法改正解説記事 (WebSearch) | 取得成功 | 制度変更のタイミング把握 |

### 取得できなかった情報源(重要な制約)
- **Amazon.co.jp = 全面的に 503 でブロック**。検索ページ・レビューページともに本文を取得できなかった。
  → **課題5「Amazonレビューの★3以下の不満」は一次情報として取得できていない。**
  代替として、Yahoo!知恵袋で「自己啓発本 意味ない」(約4,275件)「ビジネス書 役に立たない」(約2,569件)を調査し、
  **読者が実用書に対して抱く不満を、知恵袋の生の書き込みから再構成**した(後述 5章)。これは代替指標であり、
  Amazonレビューそのものではないことを明記する。
- **読書メーター(bookmeter.com) = 503**、**honto = 403**、**ブクログ = 本文空**、**教えて!goo = DNS解決不可**(セッションのネットワーク許可外)。
- **note.com = 検索結果がJavaScript描画のため本文取得不可**。API(v3/searchs)も404。
  → note の体験記は**個別記事としては読めていない**。はてブ経由で拾えた範囲のみ記載。
- **X(Twitter) = 取得不可**。5ch検索(find.5ch.net→find.5ch.io)も中身が返らず。
- WebSearch は米国インデックスのため `site:` 指定が効かず、知恵袋・note へのサイト指定狙い撃ちは機能しなかった。
  → 代わりに**知恵袋の検索URLを直接叩く方法**に切り替えて解決した。

### 件数の読み方(注意)
知恵袋検索はAND検索で、**キーワード数が増えると件数が激減する**。
例:「カスハラ 辛い」=267件 だが「カスハラ 現場 対応 スタッフ」=16件。
**異なる語数のクエリ間で件数を単純比較してはいけない。** 本レポートでは語数を併記した。

### 1-2. 頻出パターン(実際の書き込みの傾向 ※要約・個人情報は除去)

**パターンA: 「辞めても同じことになるのでは」という無限ループ恐怖**
- 「人間関係で仕事辞めても、また新しい職場になっても人間関係で辞めると思う。どうしたらいいのでしょうか？」
- 「仕事の人間関係で辛いことがあると、すぐ辞めるとどこの仕事も続かないでしょうか」
→ **「辞める／辞めない」のノウハウ本は山ほどあるが、「辞めた後も同じ轍を踏まないための対人スキル」には本が無い。**

**パターンB: 自分を責める前置き(「甘えですか」「ふざけてますか」「ズルい人間ですかね」)**
- 「人間関係で仕事を辞めたいと考えるのはふざけてますか？」
- 「12月いっぱいで退職するとズルい人間ですかね… 今すぐにでも辞めたいけど…(ボーナスが)」
- 「退職代行を使う理由がわかりません。(中略) 甘えですか？」
→ **読者は情報より先に「許可」を求めている。** 冒頭で罪悪感を解除する構成が刺さる余地。

**パターンC: 辞めるときの金銭的タイミング計算が切実**
- ボーナス前に辞めるべきか、傷病手当金と失業保険はどちらが先か、社会保険の切替、離職票が届かない等。
- 「40年勤務、定年前にメンタルでヤラれて休職、傷病手当金貰って退職する人は考えて辞めているのですか？傷病手当金貰ってから失業保険貰えますか？」
- 「休職→退職後も傷病手当金の申請をするのですが、その期間ハローワークに求人を閲覧するのって良くないですか？」
  → 回答で「1時間でも働けば傷病手当がもらえなくなる」「傷病手当受給中に失業保険申請は絶対ダメ」と警告されている。
→ **ここが最大の情報空白**(後述 6章・テーマ1)。

**パターンD: パワハラは「我慢した結果」の二次被害まで出ている**
- 「パワハラ上司に耐えてしまったがために、それがいつの間にか自分の中で痛みになくなってしまったことで、新人にもそれをしてしまう嫌いがあります」
- 「録音・日記で記録に残しています。続くようなら辞める時に訴えようと思っています」(合法的な仕返し手段への強い関心)
→ **「証拠の取り方」「どこに持ち込むか」の実務本は、法律家向け書籍はあるが当事者向けが薄い。**

**パターンE: 朝の身体症状レベルまで来ている**

→ メンタル本は多いが、**「動けないまま手続きだけ進める方法」**という実務×メンタルのハイブリッドが無い。

**パターンF: 発達障害グレーゾーンの就労が切実かつ閲覧数が高い**

### 3-2. パターンと空白

**自己肯定感 = 需要は巨大だが本も巨大(飽和)**
- 知恵袋 約31,197件 vs 楽天ブックス「自己肯定感」= **全469件**。
  出典: https://books.rakuten.co.jp/search?sitem=%E8%87%AA%E5%B7%B1%E8%82%AF%E5%AE%9A%E6%84%9F&g=001
→ **ここは避けるべき領域。** 需要÷供給が最悪。

**「職場の雑談」は需要があるのに本がほぼ無い = 狙い目**
- 知恵袋 約3,532件(3語での数字なので実質はもっと大きい) vs 楽天ブックス「コミュ障 雑談」= **全5件**。
  出典: https://books.rakuten.co.jp/search?sitem=%E3%82%B3%E3%83%9F%E3%83%A5%E9%9A%9C%20%E9%9B%91%E8%AB%87&g=101
- 書き込みの具体性が非常に高い:
  - 「お局が話題の中心で、昔の職場の話とか分からない事が多く、薄ら笑いでやり過ごしています」
  - 「ツッコミができず、皆んなぽんぽん会話してるのに自分は苦笑いかボソッとツッコんで終わりです」
  - 「『お菓子いる？』(に答えるのが苦痛)」
  - 「帰りに話しているグループがいても挨拶をして帰ってしまいます」
  - 「正社員型派遣のエンジニアなので定期的に職場が変わり、四六時中まわりが雑談していてしんどい」
→ **空白: 「雑談が上手くなる本」ではなく「雑談から降りても生き残る本」。**
  既存の雑談本は全部「できるようになれ」側。知恵袋の本音は「**加わらなくて良いのでは？**」という許可待ち。
  著者の接客・販売経験(=雑談を仕事でやらされ続けた側)は、ここで強い当事者性になる。

**毒親は量が大きいが書き込み主が10代中心**
- 1ページ目10件中、高校生・中学生・18歳が多数。閲覧数は数十〜数百と小さい。

## 5. 既存本への不満(※Amazonレビューは取得不可。代替ソースで再構成)

**制約の再掲: Amazon.co.jp は検索・レビューとも 503 でブロックされ、★3以下のレビュー本文は一件も取得できていない。**
代わりに Yahoo!知恵袋の「自己啓発本 意味ない」(約4,275件)「ビジネス書 役に立たない」(約2,569件)から、
読者が実用書に向けている不満を収集した。これは**Amazonレビューの代替指標**である。
出典:
- https://chiebukuro.yahoo.co.jp/search?p=%E8%87%AA%E5%B7%B1%E5%95%93%E7%99%BA%E6%9C%AC%20%E6%84%8F%E5%91%B3%E3%81%AA%E3%81%84
- https://chiebukuro.yahoo.co.jp/search?p=%E3%83%93%E3%82%B8%E3%83%8D%E3%82%B9%E6%9B%B8%20%E5%BD%B9%E3%81%AB%E7%AB%8B%E3%81%9F%E3%81%AA%E3%81%84

### 不満の5類型(そのまま差別化要件になる)

| 不満 | 実際の書き込み(要約) | 新刊での打ち返し方 |
|---|---|---|
| **1. 著者の経験ではないから追体験できない** | 「自己啓発本が意味ない理由は自分の経験じゃないからですか？著者の経験を追体験できるわけじゃないし」 | 一次体験のディテール(日時・数字・失敗)を全章に入れる。**著者の現場経験がここで効く** |
| **2. 中身が薄い・水増し** | 「薄くて、行間が広くて、**スッカスカの内容**のビジネス書が量産されている理由を教えてください」 | 情報密度で勝つ。1ページ1アクション。水増しの前書き・著者自慢を削る |
| **3. 記憶に残らない・それっぽいだけ** | 「**それっぽいことで肉付け**して、後で何が書いていたか記憶に残らない」 | チェックリスト・書式・テンプレートで「読まなくても使える」構造に |
| **4. 読んでも結果が変わらない** | 「こんなん読んでも年収上がるわけない」「できる奴は本読まなくても元々できる」 | 成果ではなく**手続きの完了**を約束する(=再現性100%の領域を選ぶ) |
| **5. 精神論・きれいごとへの拒否反応** | 「茶化したり、高圧的な回答はやめてください」(発達障害グレーゾーンの質問での自衛)／「大人になったら自己責任等のコメントは控えてください」(自己肯定感の質問での自衛) | 「頑張れ」「考え方を変えよう」を一切書かない。**読者は説教に殴られ慣れている** |

### ここから導かれる戦略的結論
**不満1〜5のすべてを同時に回避できるのは「手続き・制度・段取り」ジャンルである。**
- 著者の主観ではなく**事実**で書けるので「著者の経験じゃない」批判が無効化する
- 「順番」で構成するので薄まらない
- 成果ではなく「手続き完了」を約束でき、再現性が100%
- 精神論を書く余地がない
→ **既刊3冊(営業×AI、クレーム対応、スマホ仕事術)はいずれも「ノウハウ=再現性が著者依存」のジャンルだった。
  売れなかった原因の一つは不満1・4に正面からぶつかるジャンル選択だった可能性が高い。**

4. **発達障害グレーゾーンの「大人・職場」当事者**
   - 楽天49件は子ども・保護者向けに偏り、成人の職場適応は実質1冊(中村郁『発達障害・グレーゾーンかもしれない人の仕事術』)
   → 著者が当事者でなければ書けない(診断名を名乗れない人向けの配慮が必要)。

5. **心身が限界の状態で「会社と接触せずに」手続きを完了させる実務**
   - 「会社から来るように言われ続けて本当に心身ともに疲労困憊」「職場の人からのLINEを開くだけで気分悪くなる」
   - 「倒産や社長と連絡取れずで書類を書いてもらえない場合はどうすりゃいいですか？」
   → **既存の社労士本は「正しい手順」を書くが、「相手が協力しない／自分が動けない」前提で書かれていない。**
     ここは当事者経験が決定的に効く領域。

### 避けるべき領域(逆ギャップ)
- **自己肯定感**: 知恵袋31,197件に対し楽天469件。需要÷供給が最悪。
- **引っ越しの手続き**: 知恵袋29,123件と需要は巨大だが、無料記事・自治体サイト・不動産会社の案内で完全に足りる(お金を出す理由がない)。

### 上位テーマに共通する勝ち筋(5章の不満分析との接続)
1. **「順番」で売る。** サジェストが証明している通り、読者が探しているのは知識ではなく順序。
2. **「損する／やってはいけない」で入る。** 「もらえないケース」「もらわないほうがいい」「したら終わり」が上位サジェスト。
3. **精神論をゼロにする。** 読者は「甘えですか」と自分を責めており、説教に殴られ慣れている。
4. **相手が協力しない前提で書く。** 既存の制度本の最大の欠落。会社が書類を書かない、親が片付けない、医師が診断書を渋る。
5. **当事者の一次体験を混ぜる。** 不満1「著者の経験じゃない」への唯一の回答。

### 次のアクションとして推奨
1. **テーマ1・2・3 を最優先で深掘り**(深さ×空白が最大、かつ1と2は同一読者=「辞めたいが動けない人」で1冊に統合可能)。
2. **テーマ3は既刊「クレーム対応」との共食いを避ける設計が必須**。読者を「現場スタッフ本人」と「会社に守らせたい人」に切り替える。
