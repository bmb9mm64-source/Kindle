書籍「$ARGUMENTS」（books/$ARGUMENTS/ 配下）について、出版前チェックリストを実行してください。
原稿・企画メモ・ai-declaration.md を読み、各項目を ✅（OK）/ ⚠️（要対応）/ ❓（未確認）で判定し、
要対応項目には具体的な対応方法を添えてください。

## 出版前チェックリスト

### 1. タイトル・サブタイトル
- [ ] 読者の検索キーワードを含んでいるか
- [ ] 誇大表現（「必ず稼げる」「絶対」等）を含んでいないか
- [ ] 上位競合と同一・酷似したタイトルになっていないか
- [ ] サブタイトルで対象読者・得られる結果が伝わるか

### 2. 表紙
- [ ] サイズが 1600×2560px（縦横比1:1.6）か
- [ ] JPEG/TIFF、RGB、50MB未満か
- [ ] スマホのサムネイルサイズでもタイトルが読めるか
- [ ] 表紙をAI生成した場合、ai-declaration.md に記録されているか

### 3. 価格・ロイヤリティ
- [ ] 価格が 250〜1,250円 の範囲内か（70%ロイヤリティ対象価格帯）
- [ ] ロイヤリティ設定が70%になっているか
- [ ] 配信コスト（ファイルサイズ）を確認したか（画像の圧縮は済んでいるか）

### 4. KDPセレクト
- [ ] KDPセレクトに登録する設定か（70%ロイヤリティの条件）
- [ ] 他プラットフォームで同一コンテンツを販売していないか（KDPセレクトは独占契約）

### 5. AI申告（最重要）
- [ ] editorエージェントによる AI生成/AIアシスト判定が完了しているか
- [ ] books/$ARGUMENTS/ai-declaration.md が存在し、総合判定と根拠が記録されているか
- [ ] 「AI生成」判定の場合、KDP出版フォームで申告する内容（テキスト/画像/翻訳の別）が明記されているか
- [ ] 判定が未実施・曖昧な場合は出版を止め、editorエージェントで判定を完了させる

### 6. カテゴリ・キーワード
- [ ] カテゴリ選定案があるか（実用書として適切なカテゴリ2〜3候補）
- [ ] 検索キーワード7個の案があるか（読者の検索語。キーワード詰め込みは規約違反なので不可）
- [ ] 内容紹介（商品説明文）は書けているか（冒頭3行で読者の悩みに触れているか）

### 7. 本日の出版数
- [ ] 本日すでに出版した冊数を確認し、この本を出しても3冊以内に収まるか

## 出力

チェック結果の一覧表のあとに：
1. **出版可否の総合判定**（すべて✅なら「出版準備OK」、⚠️/❓が残るなら「保留」と残タスク一覧)
2. チェック結果を books/$ARGUMENTS/publish-check-YYYYMMDD.md に保存する
