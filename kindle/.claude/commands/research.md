description: テーマ候補の競合状況をリサーチし、狙い目かどうかを判定する
argument-hint: [テーマ・キーワード候補]
---

与えられたテーマ候補「$ARGUMENTS」について、plannerエージェントを使って
Kindle実用書ジャンルの競合状況を調査・整理してください。
テーマが複数ある場合は1つずつ順番に処理します。

## チェック手順

1. **検索キーワードの洗い出し**
   - テーマから読者が実際に検索しそうなキーワードを3〜5個挙げる
   - （例：テーマ「一人暮らしの自炊」→「自炊 節約」「一人暮らし 料理」「作り置き 初心者」）

2. **Amazon上位30冊の確認**（キーワードごと）
   - Amazon.co.jp Kindleストアでの検索上位30冊について、
     レビュー数・平均評価・出版日・価格・Kindle Unlimited対象かを一覧化する
   - Webで確認できない項目は「要手動確認」と明記する

3. **競合状況の判定**
   - 狙い目：上位30冊にレビュー10件未満の本が3冊以上 → 参入余地あり
   - 激戦区：上位がレビュー100件超で占有 → 避けるか切り口を変える
   - 需要なし：検索結果が少ない・古い本ばかり → キーワード変更して再確認
   - 直近1年以内の出版が上位にあるか（＝今も読者が流入しているか）も確認する

4. **切り口の提案**
   - 激戦区でも「対象読者を絞る」「体験談ベースにする」等で狙い目に変わらないか検討する

5. **結果の保存**
   - knowledge/research-YYYYMMDD-（テーマ名）.md に調査結果を保存する

## 出力フォーマット

テーマごとに：

```
## テーマ：（名前）
- 判定：狙い目 / 激戦区 / 需要なし（＋根拠となる数字）
- 上位30冊の傾向：（レビュー数の分布、出版日の新しさ、価格帯）
- 参入するなら：（推奨キーワード・切り口・仮タイトルの方向性)
- 要手動確認：（Amazonで直接確認が必要な項目）
```

最後に、調査したテーマの中での優先順位と推奨を1〜2文で述べてください。
